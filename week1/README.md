## Лабораторные работы 1 - 3

### Результаты

- Создана реляционная база данных из 16 связанных таблиц.
- Настроены первичные ключи и внешние связи между факультетами, школами, группами, студентами, контактами, мероприятиями и олимпиадами.
- В таблицы добавлены учебные данные.
- Выполнены запросы с `JOIN`, `GROUP BY` и `COUNT`.
- Получена статистика количества студентов по факультетам, школам, группам и национальностям.
- Получен список студентов из США.
- Список созданных таблиц проверен командой `\dt`.
